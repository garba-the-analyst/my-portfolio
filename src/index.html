1. Finance & Trading Apps

PRAXIS

[IN PROGRESS]

An AI guide and coach for forex and crypto traders, built as an institutional-grade intelligence platform underneath — seven purpose-built engines (execution analysis, risk management, behavioral coaching, market sentiment, and more) behind an event-sourced Rust core and a TypeScript API gateway. The security boundary is enforced by the database itself: two Postgres schemas with separate roles mean even a compromised API layer cannot write into the intelligence data. Architecture and schema are fully specified and validated against a live Postgres instance; the engines and UI are being built out now.

MiddleMan

[IN PROGRESS]

My biggest and most personal project — a non-custodial neo-bank, gift card liquidation engine, and trading terminal, all running inside WhatsApp with a real-time Vue 3 admin dashboard behind it. AI only extracts intent from natural language, including Nigerian Pidgin; it never touches a balance or executes a transfer directly — every financial state change is a compile-time-verified Rust query. Wallet keys across EVM, Solana, Tron, and TON are AES-256-GCM encrypted and held in RAM only for the millisecond it takes to sign, then scrubbed. TypeScript (Baileys) drives the WhatsApp gateway and APIs; a pure Rust backend (Axum/Tokio) handles everything that touches money.

2. Blockchain & Web3

ZeroClaw: Token Risk Check

A read-only WebAssembly plugin for the ZeroClaw AI agent runtime that screens Solana SPL Token and Token-2022 mint addresses before an agent trades them — flagging freeze authority, holder concentration, and dangerous extensions with a RED/AMBER/GREEN score.
